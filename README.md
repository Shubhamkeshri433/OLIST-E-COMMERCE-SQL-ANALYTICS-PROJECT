# Olist E-Commerce SQL Analytics Project

## 📌 Overview

This project focuses on analyzing the **Olist E-Commerce dataset** using **Microsoft SQL Server (SSMS)**. The dataset contains information about customers, orders, products, sellers, payments, reviews, and geolocation.

The project begins with **Data Profiling and Data Quality Validation** to understand the dataset and identify potential data issues before performing further analysis.

## 🎯 Objectives

* Analyze the structure of the dataset.
* Identify missing and duplicate values.
* Validate data types and data consistency.
* Detect invalid values and date inconsistencies.
* Perform SQL-based analysis to generate business insights.

## 📂 Dataset

The project includes the following datasets:

* Customers
* Orders
* Order Items
* Order Payments
* Order Reviews
* Products
* Sellers
* Geolocation
* Product Category Translation

## 🛠️ Tools & Technologies

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* SQL
* Git & GitHub

## 🔍 Current Work

The current phase focuses on **Data Profiling and Data Quality Validation**, including:

* Row and column analysis
* Missing value checks
* Duplicate record detection
* Data type validation
* Invalid value detection
* Date consistency checks

## 🚀 Future Analysis

Further analysis will focus on customer behavior, sales performance, product categories, seller performance, payment methods, delivery performance, and customer reviews.
