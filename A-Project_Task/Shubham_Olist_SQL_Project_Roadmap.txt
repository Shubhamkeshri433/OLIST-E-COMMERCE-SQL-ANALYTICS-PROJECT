OLIST E-COMMERCE SQL ANALYTICS PROJECT
ROADMAP — SHUBHAM
Dataset: Brazilian E-Commerce Public Dataset by Olist

PROJECT DIRECTION
Use the Olist public e-commerce dataset as the real-world source. Build a
Microsoft SQL Server analytics project around the data that actually exists.

Focus: sales, customers, products, sellers, payments, reviews, delivery,
geography, RFM/cohort analysis, advanced SQL, reusable SQL objects, and
performance.

Do NOT invent returns, promotions, profit, or other unsupported data.

==================================================
YOUR MAIN RESPONSIBILITY
==================================================
1. Database architecture and SQL Server setup
2. Relational model, tables, keys and constraints
3. Sales analytics
4. Customer analytics
5. RFM and cohort analysis
6. Advanced SQL analytics
7. Views
8. Stored procedures
9. Useful SQL functions
10. Indexing and performance
11. SQL validation
12. Final SQL integration

==================================================

==================================================
- Download Olist.

==================================================

PHASE 3 — DESIGN THE SQL SERVER MODEL
==================================================

- Relationships
- Constraints
- Indexes
- Naming conventions

Create an ER diagram.

==================================================

PHASE 5 — LOAD AND VALIDATE
==================================================

- Invalid numeric values
- Orphan records
